# BUA Comp Sci Website
The website for the BUA computer science club. Essentially a portfolio of everything we make with links and descriptions. Maybe will include some club members and club history (?).

Technologies:
- Vite (Bundler - Bundles and converts TypeScript and React code into vanilla JS + CSS + HTML)
- React (Its React guys, it does important stuff :P)

Start the Development Server:
1. Make sure you have [bun](bun.com) installed
2. Install dependencies `bun install`
3. Run `bun run dev`
4. Go to the website
5. You did it!! :D
